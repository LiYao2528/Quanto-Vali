# Quanto vali?

Opera web interattiva sul tema della privacy e della profilazione digitale.

## Avvio

Aprire `index.html` in un browser moderno. Per una visualizzazione completa è consigliato pubblicare i tre file su un server web statico.

## Struttura

- `index.html`: struttura semantica dell'interfaccia;
- `styles.css`: impaginazione, grafica, animazioni e adattamento mobile;
- `app.js`: domande, rilevazione locale dei dati tecnici, deduzioni simulate, avanzamento e cancellazione del profilo.

## Funzionamento

All'avvio l'opera legge localmente alcune informazioni tecniche già esposte dal browser, come lingua, fuso orario, dimensioni dello schermo e tipologia indicativa del dispositivo. Successivamente propone quattro domande. Ogni risposta viene trasformata in categorie comportamentali simulate e contribuisce alla costruzione di un profilo digitale.

Il valore economico conclusivo è simbolico e non costituisce una stima reale dei dati personali.

## Privacy

Il progetto non utilizza cookie, database, strumenti di analisi o richieste di rete. Le risposte rimangono nella memoria temporanea della pagina e vengono eliminate con il comando “Cancella il mio profilo” oppure chiudendo o ricaricando la pagina.

## Tecnologie

- HTML5
- CSS3
- JavaScript senza librerie esterne
